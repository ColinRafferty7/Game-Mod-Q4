# Midterm Project

### This project is a modification of Quake 4 meant to add features from The Binding of Isaac #

- *Press tab to open the in-game help menu*
- *The player shoots tears that can be upgraded through items*
- *On completion of each level, the player will be teleported to a random level*
- *These levels will be generated infinitely, where enemies will scale as the player progresses*
- *Use different items, such as bombs and keys, to unlock secrets throughout each level*
